# G204

<instructions>
Detects `os/exec.Command` or `syscall.Exec` calls with user-supplied arguments, enabling command injection. An attacker who controls even one argument can execute arbitrary system commands on the host. Avoid shell commands when possible; when required, pass arguments separately to `exec.Command` (never through `sh -c`) and validate all inputs against an allowlist.
</instructions>

<examples>
## Good
```go
out, err := exec.Command("ls", validatedDir).Output()
if err != nil {
    return err
}
```
</examples>

<patterns>
- Avoid shell execution with user input — pass arguments directly to `exec.Command` without `sh -c`
- Validate user-supplied command arguments against an allowlist before passing to `exec.Command`
- Replace `syscall.Exec` with `exec.Command` — validate all dynamic paths against an allowlist
</patterns>
