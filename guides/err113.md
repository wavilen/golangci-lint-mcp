# err113

<instructions>
Detects `errors.New` and `fmt.Errorf` called at runtime instead of defined as package-level sentinels, and flags `err ==` comparisons that fail on wrapped errors. Direct equality checks silently miss the actual error cause when error values are wrapped with `fmt.Errorf("%w", ...)`. Define sentinel errors as package-level `var` values and compare with `errors.Is`.
</instructions>

<examples>
## Good
```go
if errors.Is(err, io.EOF) {
    return ""
}
```
</examples>

<patterns>
- Use `errors.Is(err, target)` instead of direct `err ==` comparisons to support wrapped errors
- Declare sentinel errors as package-level `var` values, not inside function bodies
- Ensure sentinel errors used across packages are exported (capitalize the `var` name)
- Use errors.Wrap when wrapping errors to enable `errors.Is`/`errors.As` matching
</patterns>

errcheck, wrapcheck, govet
