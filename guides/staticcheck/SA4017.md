# staticcheck: SA4017

<instructions>
Detects function calls where all return values are discarded but at least one carries meaningful information — errors, computation results, or side-effect outcomes. Discarding return values hides failures from I/O, wastes pure-function results, and silently drops error signals. Assign the return value to a variable and handle it, or use `_` only with an explicit safety justification.
</instructions>

<examples>
## Good
```go
err := os.Remove("temp.txt")
if err != nil && !os.IsNotExist(err) {
    log.Printf("failed to remove temp file: %v", err)
}
```
</examples>

<patterns>
- Check error returns from `os.Open`, `os.Create`, `io.ReadAll` — discarding these hides file-not-found and permission errors
- Assign return values from `fmt.Fprintf`, `io.Copy`, etc. to check for errors
- Use or store return values from pure functions like `strings.Contains`
- Check return values from `http.ResponseWriter.Write` for errors
</patterns>
