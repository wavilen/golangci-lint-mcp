# G301

<instructions>
Detects directories created with overly permissive modes like `0777` or world-writable permissions. Permissive permissions allow any local user to read sensitive data, modify configuration, or inject malicious files into the directory. Use restrictive permissions — `0750` for shared directories, `0700` for secrets — following the principle of least privilege.
</instructions>

<examples>
## Good
```go
_ = os.MkdirAll("/var/app/data", 0750)
```
</examples>

<patterns>
- Use restrictive permissions like `0750` or `0700` for `os.Mkdir`/`os.MkdirAll` — avoid `0777`
- Set restrictive permissions (`0700`) on directories that contain secrets or config files
- Limit temp directory permissions to `0700` — use `os.MkdirTemp` which sets appropriate defaults
</patterns>
